《网页设计与制作》第六章综合实例拓展作业
网站名称：中华食味录

打开方式：
1. 解压整个压缩包。
2. 双击 index.html，使用浏览器打开。
3. 请勿单独移动 HTML、css、js、images 或 dishes 文件夹。

网站结构：
- 首页 1 个
- 菜系栏目页 4 个：川菜、鲁菜、粤菜、湘菜
- 菜品详情页 12 个：每个菜系 3 道代表菜
- 关于网站 1 个
- 合计 18 个 HTML 页面

技术说明：
网站采用 HTML5、CSS3 和原生 JavaScript 制作。所有图片、样式和脚本均保存在本地，不使用 CDN 或外链资源。页面支持桌面、平板和手机宽度。
