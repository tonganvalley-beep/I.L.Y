# 《I.L.Y.：一瞬留影》独立试玩

双击 `index.html` 即可游玩，不会修改或覆盖原游戏。

## 操作

- 跟随用户指定的《恋愛裁判.mp3》原曲，观察从远景飞向镜头的四轨音符。
- 音符到达判定线时按 `D`、`F`、`J`、`K`；触屏可直接点击下方四个按键。
- 游戏中按 `空格` 或 `P` 可暂停，再按一次继续；音乐、音符和长条会停在同一时刻。
- 音符和判定卡统一改为高对比矩形，使用不同颜色与内部符号区分轨道，远处和高速下也更容易看清。
- 远景音符采用持续加速的透视曲线：刚出现时较慢，接近判定线时明显加快。
- 普通方形音符是跟拍动作，金色圆形音符会真正按下快门并生成照片。
- 歌曲按原速完整播放；对当前 MP3 进行波形分析后，谱面采用实测约 134.88 BPM、0.413 秒起拍相位。
- 右上角可选择“标准 / 高压 / 极限”三档谱面；高压和极限会逐步增加半拍、四分之一拍与双押。
- 长条需要从头部命中后持续按住；尾部过线即自动完成，之后何时松开都不会受罚，只有提前松开会触发 `HOLD BREAK`。
- 右上角流速可在 `0.70×–3.00×` 之间随时调节，只改变音符飞行时间，不改变音乐或谱面时间。
- 右上角“闪屏”按钮可以随时关闭或恢复命中后的全屏亮光，选择会自动保存；关闭后仍保留局部粒子与判定文字。
- 音符最终坐标直接读取下方同形判定图案的中心，二者完全重合时就是准确判定时机。
- 每轨判定依次为“空拍 → 提前失败 → 成功 → 过晚失败”。空拍不消耗音符；进入失败区后按键会令该音符失败并立即消失，不加分也不倒扣分数，从而避免乱按刷分。
- 判定与音乐自身的播放时间绑定，动画偶尔掉帧也不会导致整段谱面越走越偏。
- 谱面重点拍来自用户提供的全谱面确认录像：逐帧检测黄色 `PERFECT` 爆光，提取命中时间后再映射为四轨。
- 参考录像使用约 2 分 20 秒的短版歌曲；其两处剪辑在完整 MP3 中对应的缺失段落，使用相同节奏型补谱。
- 谱面会在音频末尾无声区前约 `3.2` 秒停止生成，音乐结束后不会再残留音符。

## 剧情位置

建议插在第三章海边拍照 RPG 之前。基生举起相机后，爱理故意快速换动作；本段完成后，再进入原本的海边探索与拍照点收集。

## 设计取向

- 采用原创四轨透视界面与摄影机制，不复制参考游戏的圆形轨道、角色或界面。
- 沿用现有海边像素背景、爱理立绘、蓝白 UI 与底部无框字幕。
- 照片评价只改变结算对话，不改变主线剧情，避免玩家因节奏失误错过内容。
