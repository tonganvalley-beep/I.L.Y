# I.L.Y. 七幕 Boss 关

直接打开 `index.html`，或用静态服务器打开本目录。方向键移动，Shift 半速精调，P 暂停，R 从第一幕重开。窗口失焦自动暂停。

## 当前版本：开场连贯台词 + 后续连续弹幕
成功挑战的逻辑时长仍为 **300 秒**，包含准备与六次转场，不含加载、暂停、失败重试。
前六幕每个词条只占开场的一波，按原句顺序推进，词条之间有实际弹幕齐射；每幕台词在开场 **10 秒内** 发完，剩余波次持续发射普通弹幕。保留 **157 个真实波次**、原出波间隔和弹速，画面显示真正执行的波次。

例如第一幕：**你能 → 弹幕 → 再一次 → 弹幕 → 喊我的 → 弹幕 → 名字吗 → 连续弹幕**。
相邻词条起始间隔：第一幕 2.4 秒，第三幕 1.9 秒，第五幕约 1.67 秒，治疗幕约 1.73 秒。第一幕四段分别在幕内 1.3 / 3.7 / 6.1 / 8.5 秒开始，最后一段连发最迟约 9.7 秒完成。

### 每波确实执行的内容
前六幕分为两个阶段：
- **台词阶段**：第一幕前 4 波、其余幕前 3 波，每波连发当前词条 4～6 颗，并穿插两次环形齐射和一次主题弹幕。下一波直接说下一个词条，不再重复同一台词段多波。
- **弹幕阶段**：第一幕余下 12 波，第三幕 21 波，第五幕 30 波，治疗幕各 9 波。每波保留上述三次弹幕，再追加一次环形齐射，补充词条退场后的压力。主题弹幕继续轮换并组合本幕机制。

治疗幕的普通弹全部为治疗。后续波次按固定节奏进入，上一波的余弹自然保留；台词发射结束后，已有词条仍按寿命自然渐隐。底部提示相应切换为“连续弹幕”或“绿光回响”。
终篇没有固定句子，保留混合词条与攻击交织：每波 2～4 颗词条，至少一个治疗词和一个攻击词，**每颗词条后均穿插一轮攻击齐射**，每三波再穿插进阶攻击；终篇没有普通治疗弹与加血上限弹。

### 速度与强度
- 第 1、3、5、7 幕环形速度系数从 0.76 / 0.92 / 1.04 / 1.08 提高为 **1.00 / 1.10 / 1.20 / 1.24**。它们与基础速度、全局倍率相乘。
- 词条连续生成等待改为 12 / 12 / 10 / 10 个 60Hz 单位，实际相邻约 0.23 / 0.23 / 0.20 / 0.20 秒；不靠减慢飞行或拉长发射间隔延长关卡。
- 环形发射槽位增加到 16 / 20 / 24 / 26，每圈留一个花瓣缺口。
- 第三幕起扇形与弹墙为双轮；追踪初速、追踪强度、存续时间和上限提高；重力弹每批 14 颗；伏击每批 8 颗；泡泡每批 12 颗。
- 危险弹并存上限分别为 110 / 170 / 230 / 290，低于整个对象池 600 的容量。

## 可读性与规则
- 弹墙保留至少 100px 的空隙，并提前约 0.9 秒标出入口；激光、伏击和扇形保留预警。
- 词条逐渐放大到两倍，出现后前 0.4 秒为无伤害预告；前六幕词条寿命 3 秒，终篇 5 秒，末尾渐隐。
- 初始 HP 40，跨幕连续；受伤无敌约 0.6 秒，低血量减伤保留，第五幕与终篇最低扣 2 HP。本次加强来自波数、发射频率与弹幕组合。
- 治疗幕需要收集绿光回血。终篇治疗词朝玩家附近飞行，需要主动接近。
- 重开恢复 40 HP，并且只保留一个主循环；暂停不积累补帧。

## 实现入口
`ACTS.waves` 为实际波数，`ACTS.words` 为台词分段；`STAGES.waveEvery` 控制相邻波开始间隔，`wordGap` 控制同一波内的词条连发。
`makeTimeline` 排定完整波次，事件的 `words` 标记是否发词条，弹幕阶段的 `phrase` 为 -1。
`startWordWave` 生成开场词波，`bulletWave` 生成普通弹幕组合，`act7Burst` 生成终篇每波内容。
时间参数采用 60Hz 单位；30Hz 逻辑每步推进 2 个单位。

## 画面、迁移与视频
战斗框 560×398，Canvas 960×540，页面自适应至最大 1600px 并支持全屏。
人物保留 12fps 程序微动及出招反馈；动态开关可关闭装饰动画，危险预警始终显示。
字体共享仓库的 `sign&log/fonts/zpix.ttf`。本模块已归入 `game/minigames/boss/`，迁移或发布时须保留仓库公共资源目录结构。
图生视频提示词见 `minimax-h3-prompts.md`。将短循环视频放入 `media/`，在 `scene-media.js` 配置对应幕的路径；加载或播放失败会回退原图。
