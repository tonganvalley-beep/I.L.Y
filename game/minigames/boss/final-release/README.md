# I.L.Y. · 七幕回响

独立成品目录。双击 `index.html` 即可开始；所有谱面、图片、字体、原曲和结尾视频均已内置，无需导入文件或联网。

默认剧情难度；选择普通难度会显示红色提醒。「跳过战斗 · 继续剧情（skip）」直接跳过整个小游戏；在主游戏中返回最终章后续剧情，不是阶段选择。

开场顺序：纯黑菜单淡出 → 像素耳机提示淡入、停留、淡出 → 游戏画面淡入并开始原曲。提示期间音乐与战斗时间不推进。

操作：方向键 / WASD 移动，Shift 低速，蓝心 W / ↑ 跳跃，J / 空格射击，Z / Enter 确认下落攻击键，P / Esc 暂停，R 重开当前起点。触屏可使用画面下方按钮。嵌入模式通关或 skip 通过 boss:end 消息交还主线；菜单、失焦与退出会同步暂停/清理音乐。独立预览不包含主线剧情。

战斗使用 `boss_battle_design/chart/boss-chart-final.json` 的最终内容（640 个事件）；本目录没有编辑器、导入入口或原版模式。素材源目录均保持不变。

`resources-manifest.json` 记录复制资源的来源与 SHA-256。`chart/boss-chart-bundle.js` 是同一谱面的浏览器离线封装；保留 JSON 方便后续维护。
