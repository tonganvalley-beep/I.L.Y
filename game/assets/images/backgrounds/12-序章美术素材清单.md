# 《I.L.Y.》序章 · 美术 / 音频素材清单

> 依据：《I.L.Y.》序章可执行剧本 v1.2（11 个场景 + BR01/BR02 + NE 分支）
> 对应代码：`game/data/assets.js`（资源 id → 路径映射）、`game/data/story/prologue.js`（节点图）
> 状态：**代码框架已跑通，全部美术为占位**。只要把文件按 id 放进对应目录，即可自动生效，无需改代码。

## 用法

`game/data/assets.js` 里每行都是 `资源id : 文件路径`。把图片/音频放到该路径，
游戏里的 `background` / `portrait` / `img` 字段就会自动引用到它。
**文件缺失时不会报错**，只是背景为渐变、立绘不显示、照片格子显示「【照片 P01】」占位块——方便先跑流程后补美术。

目录约定（沿用项目既有结构，已建好 `.gitkeep`）：

```
game/assets/
├─ images/backgrounds/   背景
├─ images/characters/    立绘 / 精灵
├─ images/tilesets/      （序章不用，探索模式才用）
├─ images/ui/            道具、照片、UI 素材
├─ audio/bgm/
├─ audio/sfx/
└─ audio/voices/
```

## 八、美术硬约束（v1.2 明确要求，务必遵守）

1. **招租牌 `0A-93MC-10N4` 必须清晰可读** —— 后续调查线索。
2. **手机时间固定 18:57**（场景02 待机画面），强化停滞感。
3. **隐藏链接不得有任何提示**（无箭头、无闪烁、无系统语音），完全依赖玩家主动下滚发现。
4. **蓝光必须覆盖全局**（背景 + 手机 + 人物阴影 + 窗外霓虹）。
5. **爱理双眸为酒红色**，与十年前分毫不差；终幕不加入任何怪物化表现，异常感由静默、蓝光、年龄矛盾承担。
6. **年龄矛盾**：基生 28 岁，眼前爱理仍是高中生模样——黑屏白字需点明。
