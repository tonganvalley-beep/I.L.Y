# 小游戏与新版界面整合

主线文字以工作区的 `data/story/*.js` 和已发布的 `data/story/script-edits.js` 为准，没有用导入版本覆盖。玩法连接在 `src/core/chapter1.js` 的 `prepareChapter1()` 中组装，因此重新编译剧情不会丢失接入。

## 入口

- 第一章：寻找手柄、电脑开局及原有对白 → `ch1_battle` 的 Windows XP 桌面 → `ch1_137`（晚上七点半）。双击桌面 `games` 文件夹，可以打开原有红心弹幕或导入的三维弹球；“离开电脑”继续剧情。
- 紫阳花小径：`ch2_g2` 找回六月照片 → `ch2_photo` 节拍摄影 → `ch2_119`，继续明年六月的约定。用户最初称为第三章的花园小径，在当前工作区实际位于第二章 S04；没有把玩法误接到第三章成年爱理提到小野乃拍照的段落。
- `chapters.html` 已增加两个直接试玩入口。

摄影支持 D/F/J/K、触屏、流速调节、暂停、重玩、结算后返回或提前收起相机。成绩存于 `flags.PHOTO_RESULT`，完成标记为 `PHOTO_COMPLETED`；旧档仍兼容，新档从小游戏入口重新开始，不保存正在进行的音符或物理状态。离开、读档和回滚会销毁嵌入页面及音频。打开主菜单时摄影暂停并等待主动继续，XP 内游戏暂停并随菜单关闭恢复。

## 合并范围

从 `I.L.Y-main (2)/I.L.Y-main/I.L.Y-main` 合入 RPG/隧道分类标记、小地图提示、图标素材，以及全屏回忆、成就背景卡片和画廊布局。修复了导入版隧道画布状态未配对恢复、关闭的回忆弹窗仍占位等问题。工作区已有的楼梯地图调整和文本编辑器修改保留；回忆页也使用工作区已发布的文字及增删记录。

摄影现位于 `game/minigames/photo-rhythm`，保留四轨谱面、长条和歌曲，立绘复用公共角色图片，背景使用当前紫阳花小径回忆场景。XP 运行副本位于 `game/minigames/winxp`，不依赖下载目录。七幕 Boss 位于 `game/minigames/boss`，红心弹幕共享引擎位于 `game/src/engines/danmu.js`。两份导入目录及压缩包已在核对运行副本后删除。

## 验证

- `npm test`：包含分支图、文本保持、小游戏节点存档往返，以及七幕 Boss 的完整机制回归。已移除被删除水族馆原型专用的三项测试。
- `node tests/embedded-games-check.cjs`：需安装 Playwright 和 Edge，可用 `NODE_PATH` 指向已有依赖，`ILY_TEST_URL` 设置本地服务（默认 `http://127.0.0.1:8097`）。验证 XP 两款游戏、主菜单暂停、摄影结算回传/重玩/退出/存读档/回滚、小径探索接入及主菜单当前文本。结算测试通过触发媒体结束事件完成，不等待整首 222 秒曲目。
