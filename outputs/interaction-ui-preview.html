交互点 UI 设计稿 v1

覆盖 rpg 模式全部 7 类事件（collect / transfer / finish / clue / shop / reunion / scream）× 4 种状态。下面这块是可点的模拟画面，点标记或右侧列表切换"当前靠近的交互点"。

① 实际画面里的样子

视图模式

点选交互点（设为"靠近"）

新版：类型色徽章 + 图标，靠近时气泡锚在头顶（含类型名 / 名称 / E 键），远处只有微弱呼吸光。旧版：所有点一个金色圆点，提示固定挂在屏幕底部，与场景无关联。

② 类型规范（7 类）

颜色 = 徽章描边 / 气泡边框 / 边缘箭头 / 小地图圆点，全链路同一套色，玩家一眼分清"这是门还是线索"。

③ 状态与视觉规则

状态表现说明
未交互 类型色徽章 + 呼吸缩放 + 下方小箭头 远处也能看清"那有个东西"，但不抢戏（透明度 .9）。
可交互 放大 1.22× + 脉冲扩散环 + 头顶气泡 最近的一个点。气泡代替原来的底部胶囊，键位提示跟着点走。
已完成 灰化 + 换成勾图标 + 缩小 .86× 无动画 collect 类收集后自动变灰，避免来回跑重复触发。
未解锁 灰色描边 + 锁图标 受 flag / task 条件门控制的点（如 reunion 汇合点）。

④ 屏幕边缘指示 & 小地图图例

视野外的未完成点：画面边缘画同色三角箭头，方向指向目标；小地图用同色圆点。颜色语义与世界内标记完全一致。
