# P3 阶段报告：精细调音

日期：2026-09-16。执行：当前 Codex 会话。

## 实现

- 右侧新增按重音短语分组的精细调音面板，显示音节序号、日文、辅音与元音，支持重音位置、逐 mora 音高、辅音/元音时长及已有短语停顿时长。
- 接入 `/accent_phrases`、`/mora_pitch`、`/mora_length`、`/mora_data`。重算前说明覆盖人工编辑，可通过历史恢复。重音位置修改后须点击“重算音高”更新曲线；改变读音通过修改配音文本并重新生成结构，不修改只读 kana。
- 每句保留最多 30 步调音历史及恢复栈，随工程 JSON 保存。文本、风格、导入、批量调整和重算前保留快照。提供当前试听与上一步试听。
- 无声音节锁定音高，无辅音字段不可编辑；数值检查拒绝非有限值和越界值。音高编辑范围 3–10，时长 0–3 秒，为当前界面的制作限制。
- 基础参数修改保留现有 mora 结构，不再触发重新分析。文本或风格改变使旧查询失效；请求返回时核对快照，拒绝覆盖新编辑。试听切句或编辑时停止旧播放，丢弃迟到音频。
- 缺失风格明确要求重新选择，不自动映射成列表首项。

## 验证

- `npm test`：101/101 通过，新增测试覆盖 JSON 工程往返后的历史恢复、结构变化、无声 mora、无辅音、停顿及数值边界。
- 本机 OpenAPI 核对四个分析接口的 POST 参数；引擎 0.25.2，style 2，`テストです。`：四个接口均返回 1 个短语、5 个 mora；合成返回 39,468 字节 RIFF WAV。未保存测试音频。
- 浏览器实测：加载 1,599 句、动态 127 风格；临时输入小样并生成五个音节；两个无声「ス」音高不可编辑；首 mora 音高改为 6.2，撤销恢复为 5.8672685623168945，再恢复为 6.2。小样未保存至工程。
- 旧 8080 进程未加载当前 VOICEVOX API，另以 `node tools/serve.mjs --port 8093 --no-open` 启动当前代码进行 UI 验证。正常启动仍可使用 `npm start -- --no-open`，以终端实际端口为准。

## 使用

选择台词 → 填写日语并选择引擎原生风格 → 生成语音查询 → 在精细调音面板编辑 → 试听当前/上一步 → 保存工程。文本或风格变化后重新生成查询；可先撤销恢复旧版本。
