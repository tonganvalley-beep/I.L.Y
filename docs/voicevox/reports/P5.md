# P5 阶段报告：加固与交付

日期：2026-09-16。执行：当前 Codex 会话。

## 完成内容

- 工程存储增加结构、重复 ID、10,000 条和 20 MB 上限校验；损坏 JSON 给出 `.bak` 恢复提示。保存使用同目录临时文件、失败清理、上一版备份和进程内串行 revision 检查，防止两个窗口以同一旧版本静默覆盖。
- WAV 缓存与导出不再只检查 RIFF/WAVE 字样，现校验 RIFF 总长度、`fmt ` 与 `data` 块及块边界；截断块不会登记为完成。
- 批量导出文件名改为固定 24 位哈希并由 manifest 关联稳定 `lineId`，避免超长或特殊 ID 形成路径问题。
- CSV/TSV 增加空/重复表头、字段数、翻译状态和整数风格 ID 校验，继续保持整批事务式导入。
- VOICEVOX API 增加本机 Host、同源 Origin、`Sec-Fetch-Site`、JSON Content-Type、字节级 20 MB 请求上限和清晰 HTTP 状态；测试可注入临时根目录和模拟引擎，不触碰生产工程。
- 声音映射提取为可测试逻辑。当前引擎缺少已保存 style ID 时明确显示缺失，不自动映射列表首项。
- 工作表筛选、状态计算和分页提取为纯函数，直接用 5,000 条数据验证完整数据集搜索、章节/角色/状态筛选与 200 条分页。
- 新增 [中文快速开始](../QUICK_START.md)，覆盖启动、导入样本、调音、队列、发布、备份恢复和常见问题。

## 真实引擎抽样

本机 VOICEVOX Engine `0.25.2`，UUID `074fc39e-678b-4c13-8916-ffca8d505d1d`，动态返回 127 个风格。使用 style ID 2（四国めたん / ノーマル）对短句 `これは納品前の短い確認です。` 生成查询和音频：122,924 字节，有效 RIFF/WAVE，24,000 Hz、单声道、16-bit，按 data 块计算 2.56 秒。样本仅在内存验证，未写入工程、缓存或发布目录。

本报告只证明接口、结构和制作流程可运行。当前会话不能替用户判断日语发音、情绪或角色适配，因此不宣称完成人类听感验收；正式生产仍须对已校对台词人工试听，并核对所用音声库许可与署名。

## 交付边界

P1-P5 编辑器工作包已完成。当前没有自动生成全篇日语、全篇 WAV 或生产 manifest，也没有改变游戏中文字幕。游戏运行时语音播放、节点切换/跳过/回滚时中断、防串音、独立音量和缺失资产降级仍属于 P6，必须另行调度。
