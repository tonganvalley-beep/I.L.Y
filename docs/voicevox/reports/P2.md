# P2 阶段报告：批量制作与可靠队列

日期：2026-09-16

## 实际实现

- 多文件 TXT/TSV/CSV/JSON 导入支持 UTF-8、Shift-JIS、GB18030；CSV/TSV 支持引号与字段内换行。导入先检查缺列、未知 ID 和跨文件重复 ID，有错误时整批不应用。
- 台词工作表按 200 条分页；搜索、章节、角色和状态筛选针对完整数据集。勾选结果可批量设置声音、校对状态及基础参数，并可撤销最近一次批量操作。
- 角色默认声音和基础参数保存在本工程 `rolePresets`，不修改 VOICEVOX 全局预设。
- 新增持久化串行生成队列。任务固定保存入队快照；支持暂停后续派发、服务重启恢复、失败重试、待处理/运行中任务取消和状态轮询。
- 合成缓存键覆盖 AudioQuery、style ID、引擎身份及合成选项。结果先写临时文件，通过 RIFF/WAVE 校验并原子改名后才登记完成；取消后的迟到结果不能覆盖任务状态。
- 已完成任务可按稳定 `lineId` 导出到 `game/assets/audio/voices/generated/`，同时生成 `manifest.json`。未完成或缓存损坏的条目会阻止整次清单导出。
- 批量生产默认只接受有日语文本、已选择风格且 `translationStatus=proofread` 的条目。

## 验证证据

- `node --test tests/voicevox-batch.test.mjs`：5/5 通过。
- `npm test`：99/99 通过。
- 模拟引擎覆盖：严格串行、无效 WAV、失败后重试、运行状态重启恢复、取消后的迟到结果、5,000 条暂停队列写盘。
- 浏览器实测：本机 VOICEVOX Engine `0.25.2` 在线，动态显示 127 个风格；有效剧本 1,599 条；批量选择和批量设置弹窗可用；窄视口无控制遮挡。
- 真实引擎小样：`テストです`（style ID 2）经 `/audio_query` 与合成回退链路返回 200、39,468 字节、RIFF/WAVE 文件头；未将该临时验证音频写入工程。
- 服务运行态：编辑器、有效剧本和队列 API 均返回 200；`.mjs` 以 JavaScript MIME 提供。

## 已知边界

- 没有执行 5,000 次真实合成；5,000 条只用于解析、调度和 journal 压力检查。
- 本阶段验证 WAV 结构和接口行为，不声称完成日语听感验收。正式生产前仍需用已校对小样人工试听。
- 客户端优先使用引擎的可取消合成接口；当前 0.25.2 实例禁用了该实验能力时自动回退普通 `/synthesis`。取消始终会终止本地 HTTP 等待，但回退模式不能保证停止引擎内部计算。
- P3 的重音、逐 mora 音高/时长和精细撤销历史尚未实现；P4 的游戏增量关联和 P6 的运行时播放也未实现。
