# P6 阶段报告：游戏运行时语音接入

更新：2026-09-17。

## 实现

- 新增 `game/src/core/voice.js`：读取发布 manifest，按 `reviewId || node.id` 播放，校验 source fingerprint，串行停止旧 Audio，处理 autoplay、缺失 WAV、损坏资源和过期源文降级。
- 新增 `game/src/core/voice-source.js`：复用有效剧本与发布编辑规则生成运行时源指纹，避免编辑器与游戏 ID 漂移。
- 游戏对白、画面旁白和女主标题卡挂载时播放；节点切换、快进、回滚、读档、菜单/失焦、页面隐藏和模式销毁都会停止语音。
- 菜单增加独立语音开关和 0–100% 音量，设置保存到本地；音乐开关保持独立。
- `game/data/voice/voice-manifest.js` 提供空清单，发布音频后无需修改运行时代码。

## 已知边界

保留现有手动推进和自动演出节奏，不等待语音结束；未新增普通自动播放功能。默认语音开启、音量 80%；菜单/失焦停止且不自动续播，重新开启仅影响后续节点。浏览器首次播放仍受 autoplay 策略限制。正式 manifest 仍需由编辑器发布经过人工听审和许可确认的 WAV。
