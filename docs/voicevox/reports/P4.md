# P4 阶段报告：游戏有效剧本与增量关联

日期：2026-09-16。执行：当前 Codex 会话。

## 实现

- 复用 `script-review-model.js` 与 T1 的固定 VM 剧本加载路径，读取六篇基础剧情和已发布 `script-edits.js`。只执行仓库内固定文件，不执行用户导入的任意 JavaScript。
- 每条候选保留 `lineId`、运行时节点 ID、`reviewId`、身份类型、章节、场景、分支、角色、分类、顺序及源指纹。before 插入的代理 cue 不进入候选，代理正文以原 `reviewId` 只出现一次。
- 新增共享增量同步逻辑，预览新增、正文修改、删除、角色变化、分类变化及其他元数据变化。应用同步时保留人工日语、风格、AudioQuery、基础参数和调音历史；源指纹变化一律标记音频过期。
- 普通台词默认纳入正式配音；`monologue` 与 `heroine-card` 默认排除，可在编辑器逐句显式纳入。显式选择在后续分类变化时保留，默认选择会随分类重新计算。
- 新增正式发布动作。发布前校验工程版本、当前有效剧情 ID、源指纹、纳入状态、AudioQuery、文本、风格、query hash 与 WAV 结构；全部条目先验证通过，才写稳定 ID WAV，并原子替换 `game/data/voice/voice-manifest.js`。
- manifest 记录源版本、工程版本、源指纹、render hash、风格、角色、分类与引擎身份。P4 不加载该清单，不修改游戏运行时或中文字幕。

## 真实剧本验证

- 当前有效候选 1,599 条：1,083 条 dialogue 默认纳入，475 条 monologue 和 41 条 heroine-card 默认排除。
- 当前发布记录的 17 条新增、23 条删除和三处 before 插入继续通过既有 T1 语义验证；P4 专项测试额外断言代理正文身份、删除排除及 lineId 唯一性。
- 重复正文使用不同稳定 ID 分别保留，不按文本内容合并。

## 验证

- `npm test`：105/105 通过，含游戏既有回归、P1-P3、T1 与 P4。
- `node --check`：同步、发布、API 和浏览器脚本均通过语法检查。
- 浏览器实测本机 VOICEVOX 0.25.2、127 个风格；`1440x900` 与 `390x844` 均无横向页面溢出或控件文字截断。旁白显示默认排除，普通台词显示默认纳入。

## 使用与边界

启动服务后打开 `http://127.0.0.1:<实际端口>/game/voicevox-editor.html`。点击“同步游戏台词”查看并确认增量；完成翻译、调音和队列合成后保存工程，勾选条目并点击“发布所选”。

本阶段没有生成生产 manifest 或生产 WAV，因为当前工程没有经人工校对和确认的完整音频选择；自动化只使用临时 WAV 夹具。游戏运行时播放、中断、音量和自动推进仍属于 P6。人工日语听感与音色许可仍需制作验收。
