# T1 阶段报告：角色日语台词稿上游工具

日期：2026-09-16

## 实际实现

- 加固 `tools/voicevox/story-source.mjs`：在固定 VM 沙箱中加载六篇剧情与已发布 `script-edits`，按生效链恢复新增、删除、分类和 `before` 代理正文的真实顺序；使用 `reviewId || node.id` 作为稳定身份，并补齐章节、场景、分支与源指纹。
- 新增 `tools/voicevox/translation-workflow.mjs` 和 `tools/voicevox-translations.mjs`：导出总表及按角色 UTF-8 BOM TSV，提供稳定 ID、章节/场景/分支、原顺序、角色、中文原文、相邻上下文、日文、校对状态、备注和源版本。
- 回导支持 TSV、CSV、JSON 及目录，跨文件检查重复、未知、缺失 ID、空日文、无效状态、源文/角色/章节/版本变化；失败时事务性不写入。`--allow-missing` 支持明确的分批制作。
- 翻译工程保留当前中文源快照且只按稳定 ID 合并。正式 TXT 另带 `.ids.tsv`；仅 `proofread` 且源指纹匹配的条目可导出，和现有编辑器/批量队列门槛一致。
- 编辑器原有“导出对照稿”接口改用同一工作流，产出按角色文件。未修改游戏运行时、中文字幕或发布编辑记录，也未自动翻译全篇。

## 真实发布语义验证

- 当前发布记录中的 17 条新增均进入正确位置，23 条删除均不进入有效候选。
- 三处 `before` 插入均排在对应正文前；代理节点与 `__review_body` 共享身份时只产生一条可配音记录。
- 已发布的“台词/旁白/内心/演出”分类生效；默认角色稿只选择 `dialogue`。
- 测试覆盖按角色上下文、源文漂移、重复/未知/缺失 ID、空日文、事务失败、分批回导及仅已校对条目导出。

## 使用

```powershell
npm run voice:translations -- export
npm run voice:translations -- import game/data/voice/translations/export
npm run voice:translations -- export-ready
```

完整说明见 `docs/voicevox/T1_TRANSLATION_WORKFLOW.md`，格式样例见 `docs/voicevox/examples/translation-sample.tsv`。

- `npm test`：99/99 通过。

## 范围边界

- 未执行机器翻译，样例仅一条并标为需人工复核。
- 未自动合并角色别名；任何合并必须以后通过受审阅的显式映射配置完成。
- 日语文本的语言质量、角色口吻和读音仍需人工翻译与校对。
- 游戏播放接入不属于 T1。
