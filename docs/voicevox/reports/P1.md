# P1 阶段报告：最小端到端闭环

日期：2026-09-16

## 实际实现

- 新增 `game/voicevox-editor.html`、`game/voicevox-editor.css`、`game/voicevox-editor.js` 独立中文制作界面。
- 新增 `tools/voicevox/story-source.mjs`：在沙箱中加载六篇剧情、已发布 `script-edits` 和 `script-review-model`，按 `reviewId || node.id` 生成有效台词候选；过滤空文本、代理/删除后的 `cue` 和玩法结构节点。
- 新增 `tools/voicevox/engine-client.mjs`：固定访问 `127.0.0.1`，动态读取版本、manifest 摘要及 speaker/style；提供 `audio_query` 与 `synthesis`。
- 新增 `tools/voicevox/project-store.mjs`：工程 JSON、SHA-256 revision、`.bak` 备份和临时文件原子替换。
- 新增 `tools/voicevox-api.mjs` 并接入 `tools/serve.mjs`：引擎状态、有效剧本、工程读写、单句查询/试听、翻译 TSV 导出接口；静态服务补充 WAV MIME。
- 前端支持搜索、章节/角色/状态筛选、导入带稳定 ID 的日语稿、中文/日语并列编辑、声音风格选择、语速/音高/抑扬/音量调整、AudioQuery 生成、单句试听和工程保存。

- `node --check`（全部新增 JS）：通过
- `npm test`：90/90 通过

## 已知边界

- 未在本阶段自动合成全篇；真实 VOICEVOX Engine 未连接时界面显示离线但仍可导入、编辑和保存。
- 批量队列 journal、断点恢复、WAV 批量导出 manifest、mora 高级编辑和游戏运行时播放尚未实现，分别属于 P2-P4。
- 当前翻译 TSV 导出提供相邻上下文和源指纹；正式回导校验、重复/未知 ID 预览需在 P2/T1 加固。
