# VOICEVOX 配音编辑器快速开始

更新：2026-09-16。适用于 P6 交付版；游戏继续显示中文字幕，VOICEVOX 只合成已准备并校对的日语文本。

## 1. 启动

1. 启动本机 VOICEVOX，确认 Engine 监听 `127.0.0.1:50021`。
2. 在仓库根目录执行 `npm start -- --no-open`。
3. 访问终端打印的实际端口，例如 `http://127.0.0.1:8080/game/voicevox-editor.html`。
4. 点击右上角引擎状态重新检测。端口被占用时项目服务会自动尝试后续端口；VOICEVOX Engine 端口不随之改变。

引擎离线时仍可载入、导入和保存工程，但不能分析、试听或合成。编辑器只绑定本机回环地址，并拒绝跨站 API 请求。

## 2. 准备与导入日语稿

推荐先运行 T1 工作流：

```powershell
npm run voice:translations -- export
```

在 `game/data/voice/translations/export/speakers/` 中按角色填写日语和校对状态，再按 [T1 台词翻译工作流](T1_TRANSLATION_WORKFLOW.md) 回导。编辑器也可导入 TXT、TSV、CSV 或 JSON；结构化文件必须保留稳定 `line_id`，不能只靠行号或正文匹配。格式示例见 [translation-sample.tsv](examples/translation-sample.tsv)。

CSV/TSV 的必需字段是 `line_id` 与 `speech_text`。`translation_status` 可用 `untranslated`、`draft`、`reviewed`、`proofread`；`style_id` 如填写必须是当前引擎存在的整数风格 ID。导入会先完整校验，重复 ID、未知 ID、错误列数、无效状态或风格会使整批不应用。

## 3. 选择声音与调音

1. 选择一条台词，确认中文 `displayText` 与日语 `speechText` 对应。
2. 从动态声音列表选择 VOICEVOX 原生角色和风格。工程里的旧风格在当前引擎缺失时会显示“风格缺失，请重新选择”，不会自动改成其他声音。
3. 调整语速、音高、抑扬和音量，点击“生成语音查询”。
4. 在精细调音中修改重音位置、mora 音高、辅音/元音时长和已有停顿。重算音高、时长或全部音素会覆盖相应人工值，操作前会建立可撤销快照。
5. 使用“试听当前”和“试听上一步”对比。文本或风格改变后旧查询会过期，必须重新生成。

无声音节的音高和不存在的辅音时长不可编辑。不要修改只读 `kana` 冒充读音修改；读音变化应修改 `speechText` 后重新分析。

## 4. 批量生成、恢复与发布

只有具备日语文本、有效风格且状态为 `proofread` 的条目可以进入正式队列。队列默认串行，支持暂停后续派发、取消、失败重试和服务重启恢复。取消本地请求不保证普通合成回退模式能立即终止引擎内部计算，但迟到结果不会覆盖已取消任务。

批量导出写入 `game/assets/audio/voices/generated/`。发布时会再次检查日语文本及 `proofread` 状态；改回草稿的旧音频不能发布。完成游戏台词同步、保存工程并确认选择后，“发布所选”才会写入稳定 ID 音频和 `game/data/voice/voice-manifest.js`。P6 已接入游戏：发布后刷新游戏，在对应台词节点播放。游戏播放不依赖 Engine 在线。当前发布会以本次所选条目替换整个 manifest；需要继续在游戏中使用的已完成台词也必须一并选中，不是增量追加。

## 5. 保存、备份与恢复

- 正式工程：`game/data/voice/voicevox-project.json`
- 上一版本：`game/data/voice/voicevox-project.json.bak`
- 队列状态：`game/data/voice/voicevox-queue.json`
- 合成缓存：`game/data/voice/renders/`

保存使用版本冲突检查和同目录原子替换。遇到工程损坏提示时，先停止本地服务，保留损坏文件副本，再将 `.bak` 复制为 `voicevox-project.json`，重启服务后检查台词、声音和调音历史。不要在服务运行且页面仍可保存时直接覆盖工程文件。`.bak` 只保留上一版，重要制作节点应另行备份整个 `game/data/voice/`。

队列重启后会重新处理先前处于运行中的任务，并重新验证缓存 WAV。临时文件或只有 RIFF 字样但块长度损坏的文件不会被登记为完成。

## 6. 常见问题

**引擎显示离线**

先启动 VOICEVOX，再检查 `http://127.0.0.1:50021/version`。编辑器网页端口和 Engine 端口是两回事。

**8080 被占用**

查看终端打印的实际地址；服务器会依次尝试 8081、8082 等。也可执行 `npm start -- --port 9000 --no-open`。

**声音变成“风格缺失”**

当前 VOICEVOX 安装缺少工程记录的 style ID。重新选择并试听，不要假设同名或列表第一项等价。

**导入一条错误导致其他条目也没更新**

这是事务式导入的预期行为。按错误中的文件名和逻辑行号修复全部问题后重新导入。

**保存提示版本冲突**

另一个窗口已先保存。保留当前草稿内容，重新载入项目版本后人工合并；不要用旧窗口覆盖新版本。

**取消后 VOICEVOX 仍有短暂运算**

可取消接口不可用时会回退普通合成。本地等待已取消，迟到音频不会被采用，但引擎内部计算可能继续到当前句结束。

**已经发布但游戏里没有声音**

P6 已完成运行时播放。菜单有独立语音开关和音量，默认开启、80%。快进、回滚、读档、菜单、失焦和模式切换停止旧声音；关闭菜单不会重播，被浏览器阻止的首句直接静音，后续有手势的节点继续尝试。缺失、损坏或源文过期音频均不阻塞剧情。推进保持原节奏，不等待语音结束。

## 7. 交付前检查

运行 `npm test`，确认工程已保存、队列无失败项、所选声音许可与署名已人工核对，并用少量已校对日语在真实引擎中试听。HTTP 成功、WAV 结构和自动化测试都不能代替日语发音、情绪与角色适配的人工听审。
