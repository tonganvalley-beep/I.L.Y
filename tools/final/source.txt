一、章节总览
1.1 一句话梗概
“ILY 病毒”的真相被说出的那一夜，月色浸在蓝色的海里。她把自己的一切告诉了基生：她是靠吞食人类的身体与心而活的东西，而让人类被“吃掉”的钥匙，正是“喜欢”这句话——她本该在最初的海边就把基生吃掉，却在基生问她“喜欢是什么”的那一刻答不上来。基生回应她：他这十年真正被温暖着的，其实是倾注在“陪在他身边的 ILY”身上的感情。于是，本能的饥渴与残余的心意在她体内同时失控：她一遍遍恳求、又一遍遍拒绝着“说你喜欢我”，身体长出蠕动如虫的电线，选项在屏幕上成倍繁殖、崩坏——“说喜欢”这件事，在这个瞬间已经不可能再是纯粹的告白。崩坏的画面碎裂成一场弹幕之战（S03 Boss 战）。战后，基生抓住她逐渐虚幻的手。她拒绝吃掉他，因为那样会终结的不是一个人，而是所有彼此牵挂的人，直到人类从世界上消失；她只想在最后，仍是基生所思念的那个“ILY”。月下的蓝海里，基生的唇轻轻落在即将消失的身影上，她把最后一句话留给他——“我会永远永远，喜欢着你哦”，然后化作一道蓝光沉入深夜的大海。搜一搜“ily”：I LOVE YOU。十年之后，旧手机里那封来自 ILY 的回信依然在。基生收起翻盖手机，对晨光里奔来的儿子说：好，去海边吧。
——完。

1.3 情绪曲线与节奏说明
情绪曲线：战栗（真相落地）→ 倾诉与温柔（ILY 的羡慕与落泪）→ 心痛（基生的回应）→ 撕裂（画面中央弹出的“说喜欢我”与 ILY 的“不要”）→ 崩坏（电线与满屏“我喜欢你”）→ 高压（弹幕之战）→ 力竭（战后）→ 哀求与释然（“请不要吃掉人类”“求你什么都不要说”）→ 吻别（月下蓝海）→ 消逝（蓝光入海）→ 静默回甘（检索“ily”）→ 平静（十年之后）→ 温暖明亮（尾声·完）。
全章可拆为“一真相、一崩坏、一战、一别、一回望、一余生”：S01 把“ILY 病毒”从名词变成一件有体温的故事；S02 是全章的情感与视觉双重最高点——屏幕中央不断弹出的“说喜欢我”与 ILY 的“不要”互相撕扯，崩坏由此从心理蔓延到身体再到界面；S02-X／S03 把崩坏外化为可玩的高压段；S04 是全章落点，“不吃掉人类”是 ILY 这一存在对自己宿命的第一次、也是最后一次反抗；S05 用一次“搜索”把标题谜底轻轻掀开（ILY＝I LOVE YOU＝我爱你／再见）；S06–S07 收束到“活着的人”的日常。
节奏建议：S01 全程近乎静止——两人（或者说，一个人与一个伪装成人的身影）隔着一臂距离，靠月色、海浪与语气的落差推进；S02 的“说喜欢我”必须做成视觉冲击（画面正中央、蓝底白色大字、边缘崩坏淡出、弹出时整个背景调暗），与 ILY 清亮的“不要”形成视听对立，崩坏前的最后一句“不对！”要给一次骤然的清亮，再被崩坏吞掉；S02-X 是全章唯一的 UI 崩坏段，节流、可控、带降闪；S03 是唯一的操作高压段，BGM 硬切，战后立刻抽空环境音；S04 的分量几乎全在“停顿”与手的温度上，越是接近消逝，越要慢、要静；S05 是一次屏息般的“知道答案”的瞬间，不加旁白解释；S06–S07 收在亮处，不做感伤。
1.4 本章核心机制：崩坏选项段与弹幕 Boss 战
本章与前三章最大的不同，是它把剧情最高点交给两段“非对白”的演出：一段是【崩坏选项段】（S02-X）——把“说喜欢我”的逼问与“不要”的拒绝外化成满屏成倍繁殖的“我喜欢你”；一段是【弹幕 Boss 战】（S03）——把 ILY 体内的撕扯外化成一场必须亲手打完的战斗。二者首尾相接，构成全章唯一的“反选择—战斗”闭环。
【崩坏选项段 · Corrupted Choice】位置：S02 身体崩坏后、“你什么都不要说！”落下时。玩法：画面先浮出三个选项，内容全部是“我喜欢你”；玩家每点击一次，画面随机位置再冒出两倍的同款选项框；若玩家不点，3 秒内也会自动成倍增殖。无论点或不点，点击满 3 次（或超时 3 秒）后，整个画面崩坏，转入 Boss 战。叙事含义：这不再是“选择”，而是一次“反选择”——病毒本能诱使玩家去说“我喜欢你”，而无论说与不说，崩坏都必然发生；“喜欢”在这个瞬间已经被污染，不再可能是一句纯粹的告白。
【弹幕 Boss 战 · 接口段】位置：S02-X 崩坏之后 → S03。Boss 战为已完成工程「I.L.Y.·七幕回响」（七幕·约 300 秒·157 波），本章不重做战斗，只定义与 AVG 剧情的接口（入口参数、回调、结算变量、降闪／降恐与“剧情模式”兜底）。详细规格见附录 E。战斗结束（胜利）→ 进入 S04；失败可重试（重试不推进剧情）。

二、阅读约定与文案规范
① 行文格式：全脚本以“场景→演出指示→旁白／对白／内心”为基本单元。对白行为“说话人＋全角冒号＋台词”；无说话人的叙述行为旁白。
② 画面文本“说喜欢我”（本章专属）：S02 起，病毒求食的冲动不再由任何角色开口——画面正中央弹出一块蓝底白色大字“说喜欢我”（字块居中；边缘呈崩坏状、缓慢淡出；弹出的瞬间整个背景调暗）。它不属于任何“说话人”，是那股冲动的具象化。本脚本中，这一类画面文本以【蓝底白字块】单列，直接写出显示内容（首现为“能说你喜欢我吗”，其后统一为“说喜欢我”）；与之相对，ILY 的“不要”仍以爱理清亮的声线说出。到 S02 崩坏最高点，声源一度转为【爱理】——她已与所扮演的少女合而为一。
③ 称谓与引号（沿用第三章）：带引号的“爱理”＝那个来路不明的、伪装成爱理的存在；真正的爱理不加引号。本章 S01–S02 沿用“ILY”（她自陈“ILY 病毒”后，称谓由“爱理”转为 ILY）；崩坏最高点由【爱理】发出“不要！！”；S04 之后统一为 ILY。
④ 配色约定：绿色＝基生／生存与选择（真结局线）；红色＝病毒本能的冲撞与崩坏（含系统警告）；紫色＝崩坏选项段／特殊分支；蓝色◆＝演出、镜头、立绘、SE／BGM 指示，亦用于“说喜欢我”画面文本块；黄色＝策划注（待定项、制作注）；青色＝【Gameplay】可玩点与 Boss 战接口；灰色＝系统界面与系统提示。
⑤ 内心／心声：〔内心〕灰字斜体＝不发声的思索（多为基生）；〔心声〕＝当场流露的心声（S01 起用于 ILY 的内心，是本章第一次进入 ILY 视角）。
⑥ 系统与成就：以“▶”开头的独立段落为系统提示；成就解锁以【成就】色块呈现。
⑦ 章节存档建议：每场开头自动存档；S02-X 崩坏前、S03 Boss 战前、S03 战后（进入 S04 前）各设一次自动存档；成就「One Last Kiss」的存档点设在 S04 结束。
⑧ Boss 战两条生产线：网页直连版（本脚本默认）与 RPG 化版共用同一套战斗引擎（danmu-boss 工程）。所有可玩点均有“不操作自动通过”的兜底；Boss 战额外提供“剧情模式／跳过战斗”，保证直播、回退与测试环境可跳过操作而不丢剧情。
⑨ 恐怖与光敏合规：S02（蠕动电线／身体崩坏）、S02-X（全屏强闪烁崩坏）、S03（高频弹幕）含惊悚与强闪烁内容。原则为“给触感与声音、不给特写”，并提供“降闪／降恐”开关与前置光敏提示；恐怖强度控制在“惊悚”而非“猎奇”，避免血腥与过度身体恐怖；涉死亡与消逝的台词保持克制，不作美化。
⑩ 音乐／演出资源不在此脚本内穷举，正文以◆标注触发点，具体资源由音乐组、美术组按附录 D 的待办清单补齐。

E-0 既有工程
弹幕 Boss 战为已完成的自包含工程「I.L.Y.·七幕回响」(danmu-boss)：Canvas 渲染、七幕约 300 秒、157 个真实波次；词条“你能→再一次→喊我的→名字吗”；红＝ILY 攻击、绿＝爱理治疗；键位 方向键／Shift 低速／P 暂停／R 重开；窗口失焦自动暂停；含“动态：开／关”降闪开关；以 window.BOSS_MEDIA 配置各幕背景视频（缺失自动回退）。本章不重做战斗，只做接口。
E-1 入口接口（宿主 → Boss）
推荐以 postMessage 解耦（Boss 以 iframe 嵌入）：宿主向战斗页发送——
{ type: "boss:start", bossId: "ILY", mode: "final", actCount: 7, hp: 40, reducedMotion: <bool>, reducedFright: <bool>, bossMode: "play"|"story", lang: "zh-CN" }
备选：URL 参数版 index.html?embed=1&boss=ILY&reducedMotion=1&bossMode=story（便于独立调试）。战斗页就绪后，向宿主发送 { type: "boss:ready" }。
E-2 出口接口（Boss → 宿主）

{ type: "boss:end", win: <bool>, hp: <number>, maxHp: 40, timeMs: <number>, reachedAct: <number>, reducedMotion: <bool>, bossMode: "play"|"story" }
宿主收到后：win=true → 关闭战斗层、淡入 S04（月下蓝海）；win=false → 弹出“重新挑战／剧情模式通过”。重试不推进剧情、不回滚已读文本。
